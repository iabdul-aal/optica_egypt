# Brand Architecture

Optica Egypt Local Section Brand Identity System.

Every developer, designer, and agent working on this site must preserve separation between Optica Global corporate trademarks and Optica Egypt Local Section marks.

## Two-Layer Separation

1. **Layer 1: Global Optica (Immutable Parent Society)**
   - Official Optica trademarks, corporate logos, and tagline (`"Advancing Optics and Photonics Worldwide."`) belong strictly to Optica (Washington, D.C.).
   - Never alter, recolor, or embed Egyptian motifs inside official Optica corporate marks.

2. **Layer 2: Optica Egypt Local Section (Local Chapter Identity)**
   - Official local vector and raster brand marks live in `public/branding/` (`FullOnBlack.png`, `FullOnWhite.png`, `FullOnTransparent.svg`, `optica-egypt-logo-dark.svg`, `optica-egypt-logo-light.svg`, `optica-egypt-monogram.svg`, `IconWhiteOnBlack.svg`).
   - Design tokens (`#090c0d`, `#f8f9fa`, `#d7ae5b`, `#a67c1e`) and typography (`Montserrat` display, `Inter` body) in `app/globals.css` define the Optica Egypt Local Section web interface and must never be represented as Optica Global corporate standards.
