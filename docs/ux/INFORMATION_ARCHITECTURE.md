# Information Architecture

## Navigation (8 items ,  fixed)
Home · About · Events · Community · Leadership · Outreach · Resources · Join Us

## Page Hierarchy and Purpose

| Page | Primary User Intent | Key Action |
|---|---|---|
| Home | Understand what Optica Egypt is | Click Join or Events |
| About | Learn the mission and vision | Build trust |
| Events | Find and register for events | Click Register |
| Community | Understand who belongs | Click Join |
| Leadership | See the people behind the section | Click LinkedIn |
| Outreach | See the section impact | Build credibility |
| Resources | Find photonics resources | Click Visit |
| Join | Join the section | Submit form |

## Content Hierarchy per Page

### Home
1. Section identity (hero ,  immediate)
2. Who we serve (audience cards)
3. What is happening (events preview)
4. Latest news
5. Footer (quick links + contact)

### Events
1. Upcoming events (most important ,  action-driving)
2. Past events (credibility ,  when they exist)
3. 3D Laser Beamsplitter scene (cinematic context)

### Leadership
1. Grid of member cards (identity, trust)
2. No body copy needed ,  photos and roles speak

## Navigation Mental Model
Users think in:
- "What can I do here?" → Join Us, Events
- "Who are you?" → About, Leadership
- "What have you done?" → Outreach, Events (past)
- "What can I learn?" → Resources

Navigation order reflects this priority:
Home (orientation) → About (identity) → Events (action) → Community (belonging) → Leadership (trust) → Outreach (impact) → Resources (value) → Join (conversion)

## Empty State Strategy
Zero-portfolio launch requires honest, forward-looking empty states:
- Events: "Our first events are being planned. Follow us to be first to know."
- Outreach: "Our outreach programme is launching. Season 1 starting soon."
- NOT: blank page, "No results", or fake placeholder events
